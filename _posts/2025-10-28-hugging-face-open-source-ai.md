On October 28, 2025, I attended my very first tech event ever: a talk about 
Hugging Face and open-source generative AI, given by Niels Rogge. Niels is a 
Machine Learning Engineer at both Hugging Face and ML6, and fun fact he's 
the only Belgian employee at Hugging Face. He studied at KU Leuven and is 
actively contributing to the open-source Transformers library.

## About the event

The target audience was IT students, and the talk was pretty technical overall. It covered the 
Hugging Face ecosystem, the rise of open LLMs, and current trends in the AI 
world.

## What I learned

I had heard of Hugging Face before, but I didn't really know the full story. 
It actually started as a chatbot company back in 2016 before completely pivoting 
to open-source AI. Big names 
like Adobe, Spotify, Meta, and Microsoft all use it.

One thing that stuck with me was the distinction between closed models (like 
ChatGPT or Claude), open models (like LLaMA or Mistral), and fully open models (where everything is 
public). I never really thought about that difference before, but it matters a 
lot for things like privacy, customization, and running models locally.

Niels also showed some really practical tools I hadn't heard of:

- **Cursor**: an AI-powered code editor that uses fine-tuned models for tab 
completion. I've actually started using this myself since the talk.
- **Jan.ai**: a fully local ChatGPT alternative that runs 100% on your own 
machine, no internet needed.
- **Jupyter Agent**: an AI agent that automates data science tasks inside a 
Jupyter notebook.
- **MCP servers**: a way to connect AI apps to external tools and services, 
which is becoming a big trend.
- **Flux + LoRa**: an open image generation model that's easy to fine-tune 
for specific use cases.
- **LeRobot**: Hugging Face's initiative to democratize robotics, including 
a worldwide hackathon with 1,000+ builders across 6 continents.

The Tesla humanoid robot segment was also pretty cool to see it really puts 
into perspective how fast this field is moving.

## My takeaway

This was a great first event. As someone studying IT, a lot of the content 
connected to things I've seen in courses, especially around how open-source AI actually works in 
production and why companies choose it over closed APIs.

I've already started using Cursor in my daily workflow, which is a direct 
result of attending this talk. I'd definitely recommend similar events to 
anyone interested in AI, whether you're technical or not. Niels made the 
content accessible while still going deep enough to be genuinely interesting.

Would I attend again? Absolutely.
